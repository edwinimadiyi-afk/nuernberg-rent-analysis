# Nürnberg Rental Market Analysis 🏠
### Data Analytics Portfolio Project - Nuremberg, Germany

Analyzed 60 apartments in Nürnberg to find average rent per qm and best value districts.

**Tools:** Python, Pandas, Matplotlib, Google Colab

**Key Findings:**
- Average rent: 16.20 €/qm (Kaltmiete)
- Most expensive: Eibach (16.82 €/qm avg)
- Best value: Gibitzenhof / Gostenhof (~14.5 €/qm)
- 65qm for 950€ = 14.61 €/qm -> Good deal (below average)

**Charts:**
1. Average €/qm by Stadtteil
2. Size vs Rent correlation
3. Price distribution

**How to run:**
1. Open `NBG-Portfolio-Final.ipynb` in Google Colab
2. Run all cells
3. Or upload your own `nuernberg.csv` from ImmoScout24 for live data
